How it works

STEP 1
Co-discover a target and its yardstick
each agent picks the part of the codebase worth optimizing and builds a proxy that scores an edit in seconds
STEP 2
Keep the yardstick honest
fidelity tests invalidate yardsticks that drift; a gain counts only when the true evaluation agrees
STEP 3
Scale as a bottom-up fleet
a lightweight orchestrator spawns, terminates, and briefs agents and combines confirmed work

Abstract

Evaluation has been central to advances in AI, and it is equally critical to autonomous discovery. Yet scaling autonomous discovery to real-world engineering challenges faces a fundamental bottleneck: the cost of evaluating progress. In real settings, a single true evaluation, such as a full benchmark or serving trace, can take hours, so a search can afford only a handful of true evaluations. We present DuoDiscover, a search system that jointly discovers what to optimize and how to evaluate progress efficiently, through three mechanisms. First, each worker in a fleet of coding agents co-discovers an optimization target and a fast, tailored proxy evaluator, which we call a yardstick. The agent then hill-climbs the yardstick rather than the true evaluation. Second, since search can exploit gaps between a yardstick and the true objective, fidelity tests continually recheck each yardstick’s ranking and invalidate any that drift. Third, the fleet is bottom-up, with no central decomposition of the problem. A lightweight orchestrator spawns and terminates agents, briefs running ones, and seeds new agents with others’ confirmed work. DuoDiscover enables autonomous optimization from software to chip architecture.
