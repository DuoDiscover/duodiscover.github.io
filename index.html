Abstract

Most optimization frameworks assume candidates can be evaluated cheaply over many iterations. In practice, a single true evaluation (a full benchmark or serving trace) can take hours, so a search affords only a handful. When evaluation is the bottleneck, search must discover both a promising target to optimize and a cheap way to measure progress on it. In DuoDiscover, each agent co-discovers a target and builds a cheap proxy, a yardstick, and hill-climbs it instead of the true evaluation. A fidelity test continually checks that each yardstick still ranks edits like the true objective and drops any that drift, and every gain is confirmed on the true evaluation. The fleet is bottom-up: a lightweight orchestrator spawns, terminates, briefs, and combines agents' confirmed work; it never assigns the targets.
